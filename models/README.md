# 自动生成的低模（GLB）

由 `tools/sprite2glb/convert.py` 从本仓库贴图自动生成，每个贴图组一个 `.glb`，文件名与贴图同名（去掉 `_south/_east/_north/_west` 方向后缀）。

- 坐标：+X 东，+Y 上，+Z 南（正面），1 单位 = 1 格；`asset.extras` 记录 defName、中文名、DLC、来源贴图与像素比例。
- 建筑：斜俯视棱柱，贴图沿原视角投影（俯角 34.06°，正交）。南视图决定顶面与正面；有东视图时侧面取东视图（西侧取镜像），有北视图时背面取北视图。
- 物品：俯视薄片（顶面即原图）。
- 树木/树桩：旋转体，正面正交投影。
- 材质为 `KHR_materials_unlit`，附 `Outline` 反壳黑描边节点，可删除。
- 自动化结果：默认视角与原图高度一致；侧面、背面为拉伸采样，复杂造型（雕像、灯柱、枝杈）只是近似。
